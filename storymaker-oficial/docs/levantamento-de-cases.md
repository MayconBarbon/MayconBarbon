# Levantamento de cases — Storymaker Oficial

Lista de trabalhos de storymaker citados pela DocMe, com o que já sabemos, onde o material parece estar no Google Drive (busca feita em 18/11/2026, só pelo nome das pastas e arquivos) e o que falta.

> Os nomes de pasta são pistas, não confirmação. Antes de publicar, confira se cada pasta é mesmo do evento e se houve storymaker.
> Este arquivo não traz links nem IDs do Drive de propósito: o repositório pode ser público.

## Como preencher cada case

Para cada trabalho, o site e os e-books precisam de:

1. Evento e ano
2. Objetivo do cliente e público
3. O que foi planejado
4. O que aconteceu de diferente ou deu errado
5. Como a equipe resolveu
6. O que foi publicado no dia (links dos stories ou do vídeo)
7. Aftermovie ou entrega posterior (link)
8. Elogios, prints ou métricas
9. Autorização para usar nome, marca e imagens

Depois de preencher, os dados vão para `site/assets/js/cases.js`.
